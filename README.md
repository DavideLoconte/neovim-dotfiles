# NeoVim Dotfiles

Personal neovim configuration.

## Requirement

- Neovim: 0.12 or newer
- fzf
- fd
- ripgrep
- bat
- chafa
- npm
- cargo

Environment specific dependencies:

- Unix: git, curl or wget, unzip, gzip, and GNU tar
- Windows: PowerShell, git, GNU tar, ripgrep, and an archive tool (like 7zip)
